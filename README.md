🐍 Snake Game

📌 About the Project

This is a simple Snake Game developed using Python. The player controls the snake, collects food, and tries to achieve a high score without hitting the walls or itself.

✨ Features

- Simple and user-friendly gameplay
- Keyboard controls
- Score tracking
- Food collection system
- Game over condition

🛠️ Technologies Used

- Python
- Pygame

▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Install Pygame:
   pip install pygame
4. Run the Python file:
   python snake_game.py

🎮 Controls

- Arrow Keys: Move the snake
- Collect food to increase your score.
- Avoid hitting the walls or the snake itself.
